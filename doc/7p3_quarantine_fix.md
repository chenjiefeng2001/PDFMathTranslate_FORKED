# 7P2 — 并页粒度修复:一页折叠不再换掉整篇渲染器

修复对象是 7P2 对照实验(``doc/7p2_control_experiment.md``)暴露的缺陷:**P0 的并页检测
命中后走 ``_degrade_engine``,整篇 50 页退到 legacy 内核**,而真正出问题的只有第 7 页。

---

## 1. 原行为与代价(实测)

```
[magicpdf] ERROR 版面模型把多个源页并进了同一 render 页
           (page 6: 327 lines, 2.03pt/line, implies 5.83 page(s))
           继续渲染会产出整页叠影，按解析不可用降级
```

50 页里 1 页折叠 = 2%,却让**另外 49 页**放弃了 magicpdf:

| 指标 | 修复前(整篇降级) |
|---|---|
| 引擎 | legacy |
| 叠印页(渲染器口径) | 11 → **16** |
| 越界 span | 0 → **3** |
| 含中文页 | 42 → 47(唯一变好的) |

几何是**倒退**的。用整篇换一页不划算。

## 2. 现在的行为:逐页隔离

占比不超过 ``_MERGED_PAGE_DEGRADE_RATIO``(0.25)时,**只隔离出问题的页**:

```python
def _quarantine_merged_pages(doc, page_nums):
    # 给这些块的 translation_policy.translate 置 False
```

于是这些块走 preserve 分支(``translated = 原文``、``translate = False``),而渲染器的
``_is_translated_block`` / ``_erases_source_region`` 都以"是否真被替换"为判据:

- **不擦白** —— 不会凭空抹掉背景原文;
- **不绘制** —— 不会叠影;
- **页仍在** —— 渲染器的页集合含调用方声明的页尺寸,页数不变。

代价是这些页**不翻译**。这是有意的取舍:给一页原文,好过给一页互相覆盖的译文,或者
为它牺牲另外 49 页的排版。

只有当并页占比过高(整篇解析都不可信)时才退回整篇降级。

## 3. 同语料 / 同模型 / 同 50 页的复测

| 指标 | BEFORE(7P0,整篇降级) | AFTER(逐页隔离) |
|---|---|---|
| 引擎 | legacy | **magicpdf** |
| 叠印页(渲染器口径) | 16 | **10** |
| 叠印页(不忽略背景) | 18 | 40 |
| 越界 span | 3 | **0** |
| render-plan 块数 | — | 621 |
| 第 6 页译出中文的块 | — | **0**(已隔离) |
| 单页最多块数 | — | 201(保留在计划里,但不画) |

**越界 0、叠印 10 页,都比整篇降级好**,而且另外 49 页保住了 magicpdf 的排版。

日志如实记录了隔离:

```
[magicpdf] WARNING 版面模型把多个源页并进了同一 render 页
           (page 6: 327 lines, 2.03pt/line, implies 5.83 page(s));
           这些页将保留原文不翻译，其余 49 页照常翻译与渲染
[magicpdf] WARNING 已隔离 201 个并页块（1 页）：这些页保留原文，不翻译不重绘
```

## 4. ⚠ 墙钟 66s 是缓存,不是加速

复测只用了 **66 秒**,而 7P0 那次是 5341 秒。**这个 −99% 不能读作提速。**

翻译缓存在 ``~/.cache/pdf2zh``,第二次跑同一批文本时 585 块**全部命中本地缓存**,
一次网络请求都没发。所以两次的墙钟**不可比**。

真实的并发收益在 ``doc/7p1-concurrency/bench.json``(微基准,3.12×),要拿到整篇的
真实数字必须 ``--ignore-cache`` 重跑。``doc/7p2_compare_runs.py`` 现在会把
``translation_cache_reused`` 单独列出来,就是为了防止这个数字被误读。

## 5. 测试

15 个新测试,变异测试 6/6:

| 变异体 | 结果 |
|---|---|
| 隔离函数变成 no-op | 4 failed |
| 忘了清已回填的译文 | 2 failed |
| 整个 policy 字典被覆盖 | 1 failed |
| 隔离页集算错(隔离全部) | 4 failed |
| 降级阈值 → 0.0(任何并页都整篇降级) | 1 failed |
| 降级阈值 → 1.0(永不降级) | 1 failed |

其中"忘了清译文"第一轮**没被杀死**:我最初只在 ``translate_document`` 之后断言最终值,
而它会用 ``translate_fn`` 的返回值覆盖 ``translated``,于是变异体照样通过。补了一条
**隔离后、翻译前**的断言才杀掉 —— 同一个错误我在别处犯过(近似代替复现),这里是
"断言位置太晚"。

最要紧的一条是 ``test_isolated_blocks_are_neither_drawn_nor_erased``:隔离**不等于**
擦白。白擦了原文又不画新内容,就是凭空抹掉一页 —— 那是 commit ``63a5555`` 修过的同一类
缺陷,换个入口又回来了。

全量 **4798 passed / 16 skipped**,black clean,无新增 flake8。
